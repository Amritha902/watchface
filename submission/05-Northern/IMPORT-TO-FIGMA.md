# Put Northern into its own Figma file (about 1 minute)

1. In Figma: **New design file**, name it `05 · Northern — Titan Watch Face 2026`.
2. Drag every file from `frames-svg/` onto the canvas. Each becomes an editable vector frame (368 × 448).
3. Rename each frame to the file name (e.g. `Northern / Active Display`) and line them up left to right.
4. Optional: select all frames, press **Shift + A** for auto layout with 80 px gap, and add a text title "Northern".
5. **Share → Anyone with the link → can edit → Copy link**. Paste that link into the portal's "Figma File (Editable Link)" field.
6. Upload `Northern - preview 1x1.png` as the Final Preview Export (square, under 5 MB).

Fonts used (all free in Figma via Google Fonts): Inter, Inter Tight, Gabarito, Libre Baskerville, Bebas Neue, JetBrains Mono.
